# 摸鱼搭子 Co-Fisher

可以和朋友联机的桌面宠物：小人蹲在屏幕右下角，你一敲键盘、点鼠标它就跟着打字；敲击和点击次数攒成点数，换成 🍅 番茄 / 🦑 墨鱼汁 / 💩 屎，点好友小人下面的道具按钮，糊 TA 一脸。

- 全房间道具：🌧️ 番茄雨（糊房间里其他所有人）、🎆 烟花（全房间一起看）；☂️ 雨伞自动挡下一次攻击；托盘里的「免打扰」让被糊只显示在小人身上，全屏游戏 / 放 PPT 时也会自动这样
- 房间 Boss（16 种轮流出现）：站在好友上方，大家敲键盘、点鼠标一起扣它的血（共用一条血，按这一场同时在线的最多人数算，进进出出不会加血）；打败时伤害占 3% 以上的人每人得一个免费的 Boss 宝箱，补最后一刀的人宝箱稀有度更高，还会掉一件这只 Boss 的专属装扮（每只 5 件，稀有度越高越难掉）；之后冷却 20 分钟出下一只。宝箱（包括花点数开的）约 1/4 开出道具
- 日历：记下每天敲键盘 + 点鼠标的次数和 Boss 最后一击的次数，按当天的量给每一天上色、打评价（休息 / 摸鱼 / 搬砖 / 勤奋 / 爆肝 / 卷王）
- 单个 exe（约 12MB），用 Windows 10/11 自带的 WebView2 显示界面；只在托盘出现，不占任务栏
- 6 个 Q 版角色（Claude、Codex、豆包、Gemini、DeepSeek、Kimi），每个 1 张待机 + 3 张打字图：每敲一下键盘、点一下鼠标随机闪一张打字图，随即回到待机；也可以上传自定义形象
- 244 个装扮（5 种稀有度，其中 80 个是 Boss 专属），分头饰 / 衣服 / 宠物 / 特效四栏，每栏穿一件。新增哈基米、奶蛙、紫金 24 号、冰红茶主题共 12 件传说和 12 件神话。所有角色通用，宝箱概率不变：每 30 分钟可花 3000 点开箱，10 件同稀有度装扮可合成更高一档。
- 内置更新：启动后自动检查 GitHub Releases，有新版一键下载替换并重启
- 好友栏可以一键收起，只留自己的小人（Boss 和牌桌入口照常显示），下次启动保持
- 每个房间最多 16 人；联机方式：**Steam P2P 联机（测试 AppID 480 Spacewar，免公网/免服务器）** / 局域网房主 / 云端中转服务器 / IPv6 直连

玩家使用说明见 [docs/使用说明.txt](docs/使用说明.txt)（会随 exe 一起打包）。

## 房间小游戏（v2.8）

在现有桌宠窗口点击「小游戏」，选择 21 点、德州扑克、斗地主、四川麻将、飞行棋、中国象棋或大富翁报名。每人门票 500 点，第一位报名者开局：斗地主固定三人，四川麻将固定四人，象棋固定两人，飞行棋二至四人，大富翁二至六人，德州三至九人，21 点三至十六人。同一联机房间可同时开最多 16 张独立牌桌，每人同时参加一张；查看或观战另一桌不会退出票局，也不会扣门票。

- 21 点是无庄家的淘汰赛：A 算 1 或 11；点数最高且不爆牌者晋级，淘汰其他人。最高点数相同则继续加赛，全部爆牌则重发，直到产生一位冠军。
- 德州每人获得 1,000 局内筹码，盲注从 10/20 开始、每八手翻倍；支持跟注、加注、全下、边池和平分底池。筹码归零淘汰，最后一人获胜；局内下注不额外扣点数。
- 斗地主轮流叫分，支持单张、对子、三张、三带一/对、顺子、连对、飞机及其翅膀、四带二/两对、炸弹和王炸。地主先出完获胜；任一农民先出完，两位农民共同获胜。
- 四川麻将采用一局血战顺位赛：108 张万筒条，三张同花色换给下家后定缺，不吃牌，支持碰、明杠、暗杠、补杠、抢杠胡和一炮多响。胡牌者观战，剩余玩家继续到只剩一家或牌墙用尽。奖金按先胡顺序 700 / 550 / 350 / 0，净收益 +200 / +50 / -150 / -500；同一张牌多人胡则平分相应名次奖金。流局未胡者按听牌、未听、花猪排序，同档平分；弃权者得零，其空出奖金额补给首位未弃权的获奖组。不按番数额外扣点，整局结束统一到账。
- 飞行棋每人 4 架飞机：掷到 6 才能起飞，6 点再掷一次，连续三次 6 本回合作废；停在自己颜色的格子跳 4 格，第 18 格飞越捷径到第 30 格；落在别人飞机上会把它撞回机库。终点要刚好掷到，多出的点数往回退；四架全部到达者独得奖金。
- 中国象棋：第一位报名者执红先走，服务器判断全部走法（蹩马腿、塞象眼、炮架、九宫、将帅不能照面、不能送将）。将死或困毙获胜；双方同意和棋，或 60 回合没有吃子判和，和棋平分奖金。
- 大富翁：每局随机生成 32 格地图（四角固定，地块名称、价格、2–3 块一组的街区、机会 / 税务 / 红包格位置都随机）。开局 8 个角色各选一个、不能重复：摸鱼达人（起点工资 +100）、收租大户（收过路费 +30%）、砍价王（买地 8 折）、装修队长（升级半价）、锦鲤（机会卡只抽好事）、法务（过路费 6 折、免税）、外卖骑手（掷三颗骰子取大的两颗）、遥控大师（指定一次点数，之后冷却 3 回合）。每人 1,500 局内现金，买地、升到 3 级、整组过路费翻倍；付不起时自动半价变卖地产，仍不够就破产出局。20 轮后现金加地产总资产最高者获胜，并列平分。局内现金不影响点数。
- 奖金为最初总门票的 80%：三人桌共 1,500 点，冠军获得 1,200 点；斗地主农民获胜则每人 600 点，象棋和棋每人 400 点，其余 20% 消耗。
- 报名阶段可取消并全额退票，首位报名者退出后由下一位接任。开局后随时可以「退出牌局」，属于弃权、不退门票；斗地主一人弃权则另一方直接获胜，象棋退出即认输，大富翁退出者的地产收归银行。
- 收起牌桌、关闭面板、切换页签都不会退出。好友区的信息栏与 Boss 同排，角色昵称下方显示报名、游戏中或观战状态，点击状态可展开/收起对应牌桌。所有玩法都不限时、没有倒计时，轮到谁就等谁；已胡/淘汰者继续观战，不能操作或查看未公开的底牌。
- 轮到你时，屏幕右上角弹出「轮到你了」提示框（约 5 秒，开了免打扰或在全屏 / 放 PPT 时不弹），牌桌入口同时提示，正在看别的桌也会提醒。
- 断线超过 1 分钟才由系统代为操作（21 点停牌、德州过牌或弃牌、斗地主不叫 / 不出、麻将摸打、飞行棋掷骰、象棋优先吃子、大富翁留足 300 现金再买），重连恢复座位、手牌和未领取结算。报名凭证写入本地存档，重复消息不重复扣点或发奖。服务器重启或空房间被回收会取消未完成牌桌，重连后退回未完成的托管门票。切换联机房间前须先退票或弃权并完成结算。

房主或中转服务器也需升级到 v2.8 才有飞行棋、象棋、大富翁和不限时规则；旧版房间里新玩法显示为需要升级，原有四种照常可玩。点数仍采用原有本地存档模式，不提供现金充值或兑换。界面检查：`node tools/check-games-layout.js`，在 `tmp/games-layout-qa/` 生成实际窗口布局预览，并检查满房、状态切桌、折叠和道具遮挡；`node tools/check-board-games.js` 用真实中转的局面渲染三种新棋盘并截图到 `tmp/board-games-qa/`；`node tools/check-pet-extras.js` 检查好友栏收起和右上角提示框。

## 部署中转服务器（跨网联机）

### Docker（宝塔）

先运行 `npm run release`，把生成的 `dist/cofisher-docker.zip`（`deploy/docker/` 的文件 + Linux 版中转程序）
上传到服务器目录并解压。复制 `.env.example` 为 `.env`，
填写独立的 `RELAY_PASSWORD` 后执行 `docker compose up -d --build`。
放行 TCP **15880**，客户端填写 `服务器公网IP:15880`。容器内部端口仍为 23333。
详细步骤见 [部署说明](deploy/docker/部署说明.txt)。以后更新：上传新的 `cofisher-docker.zip` 解压覆盖，再执行 `docker compose up -d --build`。

### 直接安装为系统服务

系统选 **Ubuntu 22.04 或 24.04 LTS**（CentOS 已停止维护，不建议）。配置要求很低：1 核 1G 足够跑很多个房间，中转程序本身不到 1MB、占用几 MB 内存。

1. `npm run release` 后，把 `dist/cofisher-relay.zip` 上传到服务器并解压（或直接 `scp dist/relay/* root@服务器IP:/root/relay/`）
2. 安装为系统服务（开机自启、崩溃自动重启）：
   ```bash
   cd /root/relay
   sudo sh install-relay.sh 你的密码 23333     # 密码可以不填：sudo sh install-relay.sh
   ```
3. **在云服务器控制台的安全组 / 防火墙里放行 TCP 23333**（这一步最容易漏）
4. 朋友们在 App 里填 `服务器公网IP:23333` + 同一个房间号 + 密码

常用命令：`systemctl status cofisher-relay`、`journalctl -u cofisher-relay -f`、改密码编辑 `/etc/systemd/system/cofisher-relay.service` 后 `systemctl daemon-reload && systemctl restart cofisher-relay`。

用 IP + 端口直连不需要网站备案；只有绑定域名并走 80/443 提供网站服务时才涉及备案。

## 开发

需要 Rust（stable）和 Node.js（只用于测试和资源脚本）。

```bash
npm install                 # 测试用的 ws
npm run dev                 # 以开发模式运行 App
npm test                    # Rust 单元测试 + 协议测试（对着真实的中转程序跑）
npm run release             # 发布：dist/CoFisher/CoFisher.exe、dist/relay/*、两个 zip
npm run decos               # 重新生成装扮图片和 ui/assets/decos/decos.json（加 --preview 输出预览图到 dist/）
rustup target add x86_64-unknown-linux-musl   # 第一次发布前：用于编译 Linux 版中转程序
```

### 发布新版本（App 内自动更新）

App 会查询 `https://api.github.com/repos/silverx32/co-fisher/releases/latest`（仓库需为公开），
当 tag 版本号比自身新、且附件里有名为 **`CoFisher.exe`** 的文件时提示更新：下载 → 校验大小 / SHA256 → 把旧 exe 改名为 `CoFisher.exe.old`、换上新 exe → 重启（下次启动时删掉 `.old`）。

1. 同时修改 `app/Cargo.toml`、`app/tauri.conf.json`、`package.json` 里的版本号（例如 `2.1.0`）
2. `npm run release`
3. 在 GitHub 新建 Release，tag 填 `v2.1.0`，上传 `dist/CoFisher/CoFisher.exe`（文件名不能改），也可以附上两个 zip

更新只替换 exe，`steam_api64.dll` 等文件保持不变；房间协议版本（`PROTOCOL_VERSION`）不变时新旧版本可以互通，中转服务器建议同步更新（16 人上限、装扮同步需要新版中转；番茄雨 / 烟花 / 雨伞需要 v2.3 的中转或房主，旧版房间里会显示为暂不可用；房间 Boss 需要 v2.4 的中转或房主，旧版房间里不显示；新增的 8 只 Boss 需要 v2.5 的中转或房主，旧版房间里还是原来 8 只，它们的专属装扮照样会掉）。
Boss 的数值由房主 / 中转决定：默认每人 1500 血、冷却 20 分钟，中转可以加参数 `--boss-hp 每人血量`、`--boss-cooldown 冷却秒数` 调整（Docker 版加在 `compose.yaml` 的 `command` 里）。

角色资源：图集放在 `art/atlas/{idle,typing1,typing2,typing3}.png`（3×2 网格），`npm run slice` 切成 `ui/assets/characters/<id>/*.png`；`npm run icon` 重新生成程序图标。新增/调整角色时同步修改 `server/src/lib.rs` 的 `CHARACTERS` 和 `app/src/main.rs` 的 `CHARACTER_INFO`。Boss 在 `server/src/lib.rs` 的 `BOSSES`，可以加，已有的 `id` 不要改（专属装扮靠它对应）。

装扮：`tools/gen-decos.js` 用代码画出全部装扮（336×330 透明 PNG，覆盖角色图片框左右各加宽 20%、向上加高 25% 的区域，`layer` 为 `back` 的画在角色后面；`slot` 为 head / pet / fx，每栏同时只能穿一件）。新增装扮只往后加，不要改已有的 id（玩家存档里存的是 id）。带 `boss` 的是这只 Boss 的专属装扮：只由它的最后一击掉落，不进宝箱，合成也合不出来（但可以当合成材料）。稀有度名称、开箱概率、专属装扮掉落率（`BOSS_DROP_WEIGHTS`）、价格和冷却在 `app/src/decos.rs`。

目录：

| 路径 | 内容 |
| --- | --- |
| `server/` | 房间服务器库（App 内当房主和独立中转共用）+ `cofisher-relay` 程序 |
| `app/` | Tauri 应用：窗口、托盘、键盘鼠标计数、钱包存档、联机客户端 |
| `ui/` | 宠物窗口与糊脸覆盖层页面 |
| `test/` | 协议测试 |
| `tools/` | 切图、图标、装扮生成、发布脚本 |
| `deploy/` | 中转服务器的 systemd 服务与安装脚本 |

隐私：键盘 / 鼠标钩子只统计按下次数，不记录也不发送按了哪个键、点在哪里；每天的次数（日历）只存在本机。网络上只传昵称、角色、装扮、点数、是否在打字、是否开了免打扰、道具数量和自定义形象图片（全屏检测的结果只在本机用，不发出去）。检查更新时只访问 GitHub。
