# Board marks (象棋 / 飞行棋 / 大富翁)

Goal: Give people at a table a way to take part beyond their turns: click a board to drop a named mark that everyone viewing the table sees.

Decisions:
- Who: 象棋 spectators only (players would be hinting their own game); 飞行棋 and 大富翁 players and spectators alike. Only started or finished boards. The relay stamps the sender's room name, so names cannot be forged. Snapshots advertise `marks` (game → "spectators" / "everyone"); older hosts omit it and boards stay non-clickable.
- Where: a mark is one viewer-independent board point. 象棋: intersections 0..89 (black's flipped view maps back). 飞行棋: cells of the 14×14 grid 0..195. 大富翁: squares 0..31; its centre panel is not a point. A click on the player's own controls (a plane to move, a game button) stays a game action and never drops a mark.
- Delivery: the server broadcasts `gameMark` to the room; each client draws it if it is viewing that table. Marks never touch a table's revision, so they cannot make a player's pending move stale. Clicks faster than 6 per second per person are dropped quietly.
- Display: each person keeps at most 5 marks; the 6th drops their oldest. Every client applies this to the same ordered stream, so all viewers agree. Animation: fade in while growing and dropping onto the point, bob, fade out after 2 s. The table UI is re-rendered often, so marks carry their age and resume their animation instead of restarting. Marks float in a layer above the board (the 大富翁 board clips its rounded edges), coloured per person by an FNV-1a hash of the id.

Verification: Rust test (象棋 players refused and spectators allowed, never in the lobby, no revision change, flood limit, per-person allowance, 飞行棋 / 大富翁 players and spectators allowed with their point ranges, games without marks refused); relay WebSocket tests (象棋 spectator mark reaches both players, the spectator and an unrelated room member with the room name despite a spoofed name, players get an error; a seated 大富翁 player's mark reaches the table); `tools/check-board-games.js` (象棋 spectator: nearest-point click, relay mark with name on its point, gone after about 2 s, five per person with the oldest dropped, separate per person, survives re-render; 飞行棋 / 大富翁 players: cell / square clicks mark, plane and game-button clicks never do, the centre panel is ignored; 飞行棋 / 大富翁 spectators: relay marks centred on their cell / square, top-row labels unclipped).
