# Multi-table, presence and Sichuan blood battle

Goal: Keep game controls clear of pets, counters and inventory, support parallel tables inside one social room, and add Sichuan Mahjong plus 24 high-rarity cosmetics.

Confirmed decisions:
- Mahjong is four-player Sichuan blood battle, replacing the earlier national-standard preference. One round, payout follows order of winning hands: 700 / 550 / 350 / 0 out of four 500-point tickets. These net +200 / +50 / -150 / -500. Simultaneous wins split the occupied prize places; a draw ranks remaining players by ready / not ready / missing-suit violation. Forfeits receive zero; unused forfeited prize shares go to the first remaining winning group. No extra wallet-point bets or fan multipliers.
- 108 numbered tiles, three-same-suit exchange to the next seat, declared missing suit, no chi, peng, exposed/concealed/added kong, robbing an added kong, multiple winners on one discard, standard four-groups-and-pair or seven pairs. Hand winners observe while the remaining players continue. Final wallet settlement happens once the entire table finishes.
- Each social room can run up to 16 separate tables. Each player enters at most one unresolved table; spectating another table never changes membership or charges points. Table IDs and per-table revisions prevent commands reaching a different game or invalidating unrelated tables.
- Wallet receipts share a room ledger and epoch. Per-table receipt caches prevent a completed older table overwriting a later table's receipt. Pending joins persist their selected table ID/new-table intent across reconnects.
- Table entry and Boss share a horizontal information row, in normal layout flow. Player status labels live under names and toggle the corresponding table on click. Panel clearance follows the actual stage height, including two rows of friends. No closing/collapsing control sends a game-leave operation.
- Add 12 legendary and 12 mythic meme-inspired items in four themes: hissing cat/Hajimi, laughing yellow/green-eyed Naiwa, purple/gold #24 basketball, iced-tea clothing/bottle. Add a separate clothing slot while preserving all previous IDs and art, chest odds, and existing saves.

Verification: Rust unit tests for legal hands, shuffle/privacy, claims, gang/rob-kong, forfeits, ranks, multi-table wallet isolation and old-game compatibility; WebSocket test through the actual relay for four-seat exchange/que/discard and spectator privacy; browser fixture checks 4/15 friends, status toggles, table switching and no action-button occlusion. Build client and both relay targets, compare packaged binaries and versions. Real four-person/Steam/Docker acceptance remains separate.
